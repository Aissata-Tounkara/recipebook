Getting Started

TheMealDB API is designed to be simple to test in a browser while still supporting production use with a supporter key. The free tier is ideal for development and educational use, while premium access expands the API with the beta V2 endpoints and additional limits.

AI Agents & OpenAPI

These public, machine-readable resources help people, AI agents, Swagger, and code generators understand and integrate TheMealDB. The OpenAPI files contain placeholders only and do not expose API keys; supply your own key when making requests.

AI Agent Guide Capabilities, API workflow, response fields, attribution, and responsible-use guidance. /AGENTS.md AI Skill Reusable instructions for finding, checking, and presenting meal data accurately. /SKILL.md OpenAPI V1 Swagger-compatible specification for the stable V1 JSON endpoints. /api/spec/openapi-v1.yaml OpenAPI V2 Swagger-compatible specification for the V2 JSON endpoints and discovery methods. /api/spec/openapi-v2.yaml

Authentication

V1 uses the API key directly in the URL path, which makes it easy to test in a browser. V2 uses the same format just with an updated v2 base URL. For premium access, replace the test key with your supporter key.

V1 base URL
https://www.themealdb.com/api/json/v1/
Premium V2 base URL
https://www.themealdb.com/api/json/v2/
Free key
/1/
Premium key
/YOUR_API_KEY/
Production note If you are shipping an app publicly, you should become a supporter to get a production API key and access the unlimited V2 endpoints.

V1 API Reference

These are the core meal endpoints available in V1. The examples below use the free test key 1.

Search endpoints

Free

Search meal by name

themealdb.com/api/json/v1/1/search.php?s=Arrabiata

Search meals by their full name.

Free

List meals by first letter

themealdb.com/api/json/v1/1/search.php?f=a

Return meals whose names begin with the given letter.

Lookup endpoints

Free

Lookup full meal details by ID

themealdb.com/api/json/v1/1/lookup.php?i=52772

Lookup the full recipe payload for a meal.

Free

Lookup a single random meal

themealdb.com/api/json/v1/1/random.php

Return one random meal.

Premium only

Random 10 meals

themealdb.com/api/json/v2/1/randomselection.php

Return a larger random meal selection for supporters.

£10 lifetime upgrade
Premium only

Latest 10 meals

themealdb.com/api/json/v2/1/latest.php

Return recently added meals from the premium V2 API.

£10 lifetime upgrade

List and filter endpoints

Free

List categories

themealdb.com/api/json/v1/1/categories.php

Return all meal categories.

Free

List all Categories, Areas, Ingredients

themealdb.com/api/json/v1/1/list.php?c=list
themealdb.com/api/json/v1/1/list.php?a=list
themealdb.com/api/json/v1/1/list.php?i=list

Get browseable lists for categories, areas, and ingredients.

Free

Filter by main ingredient

themealdb.com/api/json/v1/1/filter.php?i=chicken_breast

Filter meals that include a single ingredient.

Premium only

Filter by multiple ingredients

themealdb.com/api/json/v2/1/filter.php?i=chicken_breast,garlic,salt

Multi-ingredient filtering is available on the beta V2 API for supporters.

Images

TheMealDB includes meal and ingredient artwork. Meal images support preview variants, and ingredient artwork uses the ingredient name in the filename.

Meal thumbnail images

Add /small, /medium, or /large to the meal image URL.

/images/media/meals/llcbn01574260722.jpg
/images/media/meals/llcbn01574260722.jpg/small
/images/media/meals/llcbn01574260722.jpg/medium
/images/media/meals/llcbn01574260722.jpg/large

Ingredient thumbnail images

Add /small, /medium, or /large to the ingredient image URL.

/images/ingredients/olive_oil.png
/images/ingredients/olive_oil.png/small
/images/ingredients/olive_oil.png/medium
/images/ingredients/olive_oil.png/large
